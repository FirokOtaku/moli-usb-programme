# Moli USB programme

本项目集是面向 **墨砺工作室** 开发出品的几款 USB 屏幕的二次开发内容.

项目集目前包含如下内容:

- Java 语言
  - [ ] 协议库
  - [ ] 上位机实现 (JavaFX)
- Dart 语言
  - [ ] 协议库
  - [ ] 上位机实现 (Flutter in Windows \ Web)

协议库和上位机均基于墨砺工作室提供的开源 Python 实现复刻重写.

> 请注意, 本项目集内容仍在开发过程中,
> 各子项目功能尚未完成开发, 已有内容可能并不能稳定工作
